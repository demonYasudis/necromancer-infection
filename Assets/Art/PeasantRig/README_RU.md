# Крестьянин: прототип для Unity

Откройте `Assets/Scenes/PeasantRigPreview.unity` и нажмите **Play**.
Слева находятся остановка, ходьба, бег, темп, длина шага, сумка,
отсоединение/восстановление руки и ручной просмотр фазы.

`Assets/Prefabs/PeasantSpriteRig.prefab` — самостоятельный визуальный prefab:
11 частей тела и сумка создаются при запуске. Один набор изображений,
двухзвенная обратная кинематика, опорная и переносная фазы стоп.
Ноги сдвинуты на половину цикла, руки движутся навстречу ногам.

В игровых сценах prefab уже подключён дочерним объектом `PeasantVisual` к
`Civilian.prefab`, с масштабом 0,55 и выключенным `PreviewWalking`. Старые
примитивы тела скрыты, их именованные точки сохранены для существующей
`CombatMotion`. Все жители и посыльный наследуют новую внешность из prefab.
`CivilianSpriteVisual` выбирает длину цикла для ходьбы/бегства, зеркалит модель
по горизонтальному движению относительно камеры, передаёт сгибание при
заражении и реакцию на попадание. Заражение окрашивает спрайты прежним
`MaterialPropertyBlock` из `Civilian`. Поведение и коллайдеры остаются на корне.

Фаза зависит от пройденного расстояния, телепортация не создаёт шагов.
`Stride` задаёт длину полного цикла в мировых единицах. Модель ориентируется
по `Camera.main`; рисунки поддерживают один ракурс 3/4 сверху и зеркальное
отражение. `Paused` останавливает позу и падение руки; общая пауза через
`Time.timeScale = 0` также поддерживается.

`SetPouch`, `DetachArm` и `RestoreArm` управляют демонстрацией экипировки
и отсоединения. `PouchSocket` указывает на трансформ сумки. При отсоединении
рука сохраняет позу и затем падает отдельной веткой. Столкновений и игрового
урона у неё нет; это демонстрационная функция просмотрщика. В игре заражение,
получение урона, гибель и превращение используют существующие компоненты
жителя. После превращения появляется прежний зомби; его арт ещё не заменён.

После неудачной первой сборки основа перерисована: текущий prefab использует
`Assets/Art/PeasantTopDown/peasant-complete.png`, цельного человека, созданного
встроенным imagegen. Части извлечены из него по суставам скриптом
`tools/cut_peasant_topdown.py`; точки крепления сохранены в `PeasantTopDown/rig.json`.
При остановке восстанавливается исходная цельная поза. При движении детали
поворачиваются с сохранением пропорций и длины костей. Исходный архив сохранён
в `Reference`; сумка взята из него. Промпт нового рисунка —
`Previews/peasant-topdown-prompt.md` (редактирование ракурса) и
`Assets/Art/PeasantRigV3/PROMPT.md` (исходный цельный персонаж).

Это ещё не финальная анимация: остаются швы при сгибании плоских частей,
нет переката стопы, отдельного бега и других ракурсов. Кнопка Run ускоряет
и расширяет тот же цикл. Дополнительные направления требуют рисунков.

Проверки: меню **Necromancer Infection → Peasant Rig → Run Checks and Capture**.
Пакетный запуск: `NecromancerInfection.Editor.PeasantRigSetup.RunBatch`;
проверки в Play: `NecromancerInfection.Editor.PeasantRigPlayChecks.RunBatch`;
игровое подключение: `NecromancerInfection.Editor.PeasantGameChecks.RunBatch`.
Пределы сгибания ног, сохранение соединения коленей и пропорций во всех
фазах ходьбы/бега и обоих отражениях:
`NecromancerInfection.Editor.PeasantLegChecks.RunBatch`. Для плоских деталей
ног ограничено отклонение от нарисованной позы до 18 градусов; амплитуда
подбирается сразу для всего цикла с сохранением длины костей. Так ноги не
замирают на отдельных фазах из-за покадрового ограничения угла. Колени
сгибаются в одном направлении, стопы движутся по узким параллельным траекториям.
Проверка плавности движения суставов, контакта стоп с землёй и положения
ног — `PeasantLegChecks.RunSmoothBatch`; предпросмотр из 60 кадров —
`Previews/peasant-walk-smooth.gif` и `Previews/peasant-run-smooth.gif`.
Снимки и 24 фазы цикла сохраняются в `Logs/peasant-*`.
