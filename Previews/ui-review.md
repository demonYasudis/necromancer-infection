# Проверка интерфейса — задача UI №8

Дата: 5 ноября 2026. Unity 6000.3.24f1.

Проверено текущее оформление демоверсии. Игровые сцены и prefab не изменены: дополнительные юниты, контрастные материалы земли и большие значения существуют только в проверочной попытке.

В старых HUDChecks и NotificationChecks отключена прогрессия только на время их изолированных сценариев: созданные ими юниты и убийства раньше открывали карточки и останавливали проверки боя. Остановка и продолжение при настоящем повышении уровня отдельно проверяются ProgressionChecks на обеих сценах.

## Повторение проверки

В редакторе: **Necromancer Infection → Run Interface Review**. Полный прогон последовательно выполняет HUDChecks, NotificationChecks, ProgressionChecks, FinaleChecks, бой толпы и проверку текста.

Для запуска редактора с автоматическим сохранением Game View и завершением процесса используйте `-executeMethod NecromancerInfection.Editor.InterfaceReviewChecks.PreviewBatch`. Для проверок без снимков — `-batchmode -executeMethod NecromancerInfection.Editor.InterfaceReviewChecks.RunBatch`. Графический рендеринг требуется: проверки финала снимают изображение с камеры, поэтому `-nographics` не подходит.

Успешный прогон: `Logs/ui8-review.log`, последняя отметка `PASS: Interface review and Game View captures passed.`

Эта проверка не закрывает оставшиеся пункты подготовки детализированного комплекта графики в ранних разделах UI_ROADMAP. На маленьких окнах текст заметно мельче; снимки сохранены в исходных разрешениях для оценки без увеличения.
