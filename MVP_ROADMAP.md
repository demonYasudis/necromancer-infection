# Necromancer Infection — актуальные задачи

Обновлено 8 ноября 2026 года. Порядок: камера → орда → графика → меню.

Этот список заменяет выполненные задачи прототипа и прежний план интерфейса. Задачи будущего выживания сохранены в [LEVEL_ROADMAP.md](LEVEL_ROADMAP.md). Визуальное направление — [ART_DIRECTION.md](ART_DIRECTION.md).

## 1. Камера — разворот к врагам на финальной точке

Выполнено. Камера берёт направление по точкам появления защитников. В DemoLevel и JourneyLevel она смотрит обратно вдоль дороги под более крутым углом, чтобы крыша фермы не перекрывала клики рядом с некромантом.

### Что сделать
- [x] При начале финального столкновения плавно поворачивать камеру к подходу врагов.
- [x] Держать некроманта ближе к низу экрана, фронт боя и ферму — в видимой области.
- [x] Стабилизировать направление камеры на весь бой.
- [x] Учесть финалы Tutorial1–4 и существующие DemoLevel и JourneyLevel. В Tutorial1 камера сохраняет направление маршрута.
- [x] Проверить клики заражения и защиты после разворота, паузу и повтор уровня.

### Готово, когда
Враги видны до сближения с игроком, камера поворачивается плавно, цели доступны для клика на обычном и широком экране.

## 2. Орда — плавное движение единым фронтом перед некромантом

Выполнено. Орда занимает постоянные места в рядах перед некромантом, сужает строй у препятствий и поворачивает к подходу защитников вместе с камерой.

### Что сделать
- [x] Разделить движение к месту и коррекцию при тесном сближении, добавить торможение перед остановкой.
- [x] Закреплять места и сохранять доступную цель во время преследования.
- [x] Держать широкий фронт перед некромантом и добавлять ряды при росте орды.
- [x] Сохранять свободное пространство возле некроманта.
- [x] Перестраиваться на поворотах, сжиматься в проходах и расширяться после них.
- [x] Давать приоритет целям перед строем и сохранять цепное заражение.
- [x] Разворачивать фронт к финальным врагам согласованно с камерой.

### Готово, когда
Группы из 5, 20 и 50 зомби идут перед некромантом, не окружают его и не дрожат при остановке. Проверены тесное сближение, бой, превращения, повороты, узкие проходы, финал и повтор.

## 3. Графика — доработать спрайты и оформить деревню

Выполнено в DemoLevel, JourneyLevel и Tutorial1–4. Для утверждённых персонажей добавлены задние ракурсы и позы, связанные с игровыми действиями. JourneyLevel и учебные сцены используют общий префаб расстановки декора.

### Что сделать
- [x] Собрать участок деревни с дорогой, домами, заборами, растительностью и жителями.
- [x] Проверить масштаб и читаемость на игровой камере, включая финальный разворот.
- [x] Доработать направления спрайтов и анимации ожидания, ходьбы, атаки, попадания, смерти и заражения.
- [x] Оформить маршрут от окраины через деревню до финальной фермы.
- [x] Разместить поля, телеги, бочки, ящики, колодцы и сараи.
- [x] Проверить проход широкого строя у новых зданий, видимость боя и клики после разворота.

### Готово, когда
Деревня выглядит цельной, типы персонажей различимы в толпе, а весь маршрут проходим. Есть снимки образца, боя большой орды и финальной фермы из настоящей игры.

Игровые кадры сохранены для [деревни](Previews/village-road.png), [боя орды](Previews/village-horde-battle.png) и [финальной фермы](Previews/village-farm-finale.png).

## 4. Меню — главное меню, пауза и настройки

Выполнено. Сборка начинается с главного меню. Esc открывает паузу, а настройки музыки, эффектов и экрана доступны из обоих меню.

### Что сделать
- [x] Добавить главное меню с кнопками «Играть», «Настройки» и «Выход» и запуском обучения.
- [x] Добавить паузу по Esc с продолжением, настройками, перезапуском и возвратом в главное меню.
- [x] Сохранять отдельную громкость музыки и звуков и полноэкранный режим между запусками.
- [x] Добавить возврат в главное меню с экранов победы и поражения и сохранить переход между уроками.
- [x] Согласовать паузу с карточками улучшений и результатом и блокировать клики по миру через меню.
- [x] Проверить в Windows-сборке сброс попытки и восстановление времени после паузы.

### Готово, когда
В сборке без редактора работает цикл: запуск → меню → игра → результат → повтор или меню. Настройки сохраняются, Esc корректно останавливает и продолжает мир.
